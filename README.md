# SentinelOps

## A Hands-On Security Operations and Threat Detection Lab

SentinelOps is a cybersecurity and DevSecOps project focused on building a practical security monitoring and threat detection environment.

The project will collect and analyse security logs, detect suspicious activity, generate structured alerts, and support basic incident investigation.

## Project Objectives

- Collect and analyse security-related logs
- Detect suspicious authentication activity
- Generate alerts with severity levels
- Investigate security events
- Map selected detections to MITRE ATT&CK techniques
- Automate security monitoring workflows
- Integrate industry-relevant security tools

## Initial Technology Stack

- Ubuntu Linux
- Python
- Docker
- Git and GitHub
- Wazuh (planned)
- Sigma (planned)
- MITRE ATT&CK
